# AI 广告短视频制作 Agent · 静态演示

一个以自然语言为入口的广告短视频制作系统。用户用一句话描述目标，Agent 读取品牌资产与制作规则，把需求拆解为脚本、人物、镜头、声音和验收任务，再完成关键帧、视频生成、剪辑与质检。

本仓库是静态演示版：回放 YANSHI 矿泉水广告的完整制作记录，无后端、不连接任何服务。

## 特点

- 一句话启动完整制作流程。
- 人工确认节点：脚本、人物锚定、关键帧、品牌贴标与版本选择等关键环节等待确认，保持质量可控。
- 局部重跑：只重做有问题的镜头，不必推翻整条视频。
- 版本可追踪：脚本、图片、片段、成片与质检记录进入同一条版本链。
- 自动质检：抽帧、转写、响度与成片检查均保留过程证据。
- 效率：原本约四小时完成一条视频，提升至约一小时完成五条。

## 查看

直接打开 `index.html`，或在仓库目录运行 `python3 -m http.server 8000` 后访问 `http://localhost:8000`。
